# Озвучка промо панели (ролик для телефона)

Одна-две короткие фразы на сцену. Текст в блоках ```voice``` уходит в ElevenLabs как есть: английские
слова записаны так, как их произносить. id блока = id сцены в `src/Main.tsx`; сцена вытягивается
под длину фразы (`src/voice.json` пишет `promo/nexus-review/voice/synth.py --manifest`).

```voice id=hook
Пять фишек, которых нет в других ви-пи-эн-панелях.
```

```voice id=cdn
Первая — маскировка через российские си-ди-эн. Ви-пи-эн работает даже при белых списках.
```

```voice id=routing
Вторая — маршруты по сервисам: банки через Россию, а Телеграм и нейросети — через Европу.
```

```voice id=stateAi
Третья — центр состояния. Панель сама находит проблемы, а нейросеть подсказывает, что чинить первым.
```

```voice id=updates
Четвёртая — все ноды обновляются одной кнопкой. Если что-то пошло не так, нода сама откатывается.
```

```voice id=migrate
Пятая — переезд с Ремнавейв, Марзбан, три-икс-ю-ай и три-икс-ю-ай стор. Клиенты переезжают со своими сроками.
```

```voice id=chapter
И всё, что нужно каждый день.
```

```voice id=dashboard
Выручка, клиенты и ноды — на одном экране.
```

```voice id=nodes
Все ноды и их статус — в реальном времени.
```

```voice id=users
Любой клиент находится за секунду.
```

```voice id=payments
Клиент оплатил — подписка продлилась сама.
```

```voice id=outro
Нексус — панель для своего ви-пи-эн-сервиса. Демо и вопросы — в Телеграме.
```
