# Промо панели Nexus (Reels / Shorts)

Вертикальный ролик 1080×1920, 30 fps, 26,5 с, без голоса: субтитры, звуки, музыка.
Сделан по скиллу [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)
(`.claude/skills/video-shotcraft/`), режим «автономное создание» (`references/pipeline.md`).

Готовые файлы: `docs/nexus/promo/nexus-panel-promo.mp4` (с музыкой),
`…-nobgm.mp4` (только звуки — под свою музыку в редакторе соцсети),
`…_cover.png` (обложка = первый кадр). Громкость сведена к −14 LUFS.

## Бриф и решения

| Вопрос | Решение |
|---|---|
| Для кого | Те, кто держит свой VPN-сервис: им продаём панель (`docs/nexus/README.md`) |
| Что должен вынести зритель | «Всё в одной панели»: деньги, ноды, клиенты, автопродление; где взять — @Nexus_dev, от 3 990 ₽/мес |
| Формат | 9:16 под Reels/Shorts, ≤30 с (`docs/nexus/style-guide.md`) |
| Данные | Только выдуманные: демо-заглушка `capture/demo-brain.py` (решение владельца) |
| Что снимаем | Настоящую панель (код `vgx3d/frontend`), мобильную вёрстку: 540 px CSS = кадр ×2 |
| Вид | Тема Nebula панели + цвета концовки канала (`src/theme.ts`) |
| Звук | Mixkit с известными источниками (`ATTRIBUTION.md` скилла); музыка «House Vibez» (Lily J), с 2-й секунды |

## Отступления от правил скилла (осознанные)

- **promo-energy-arc** советует начинать с бренда. У шортсов досмотр решают первые 2 с, поэтому
  первый кадр — тезис-обложка, а бренд — в концовке (`docs/nexus/style-guide.md`).
- **R4/музыкальная сетка**: склейки не подогнаны под доли — librosa на машине не было. Музыка
  ровная (123 BPM), склейки прикрыты вспышками; при желании подогнать — `references/music-beat-sync.md`.
- **S5**: смещение звука после кодирования AAC (~1 кадр) не измерялось и не компенсировано.
- Независимая проверка (`references/final-review.md`, отдельным агентом) не проводилась —
  проверял сам: стоп-кадры каждой сцены, кадры из готового mp4, резкость текста на наездах, громкость.

## Пересобрать

```bash
# 1. Панель на демо-данных (репозиторий vgx3d)
python3 promo/nexus-panel/capture/demo-brain.py 8099 &
cd ../vgx3d/frontend && npm ci && BRAIN_INTERNAL_URL=http://127.0.0.1:8099 npx next build
BRAIN_INTERNAL_URL=http://127.0.0.1:8099 npx next start -p 3100 &

# 2. Съёмка: текстуры в public/textures, координаты в src/layout.json
cd promo/nexus-panel && npm ci
node capture/capture.mjs http://127.0.0.1:3100   # нужен Playwright с Chromium

# 3. Проверка и рендер
npm run typecheck
npx remotion still src/index.ts NexusPromo out/qa/f300.png --frame=300
npm run render && npm run render:nobgm && npm run master   # out/*-master.mp4
```

`npm run dev` открывает Remotion Studio. Тексты сцен — в `*_DEFAULTS` каждой сцены и в
`CAPTIONS` (`src/Main.tsx`, `*слово*` — розовая плашка).

## Подводные камни (уже наступили)

- **Шрифт грузить внутри компонента** (`useFonts`), не на импорте модуля: иначе `delayRender`
  остаётся висеть, и полный рендер падает по таймауту, хотя стоп-кадры и короткие куски проходят.
- **Не класть огромные слои в 3D под `zoom`.** Стол 5340×5900 px под ×2,6 ронял вкладку рендера;
  фон стола теперь в экранном пространстве.
- Рендер в 2 потока (`remotion.config.ts`): на 4 vCPU с 3D-сценами больше не быстрее.
