Статус на 24.10.2026: **сценарий на согласовании** — `docs/nexus/review-v2.md` (≈5,6 мин, 4,7 тыс. символов голоса).
Готовы: пробная живая запись экрана, скрипт озвучки `voice/synth.py`. Аккаунт ElevenLabs заведён (бесплатный, 10 000 кредитов).
Делаем скиллом video-shotcraft (`.claude/skills/video-shotcraft/`) — тем же, что и шортс `promo/nexus-panel/`.

## План (решения владельца, 24.10)

1. **ElevenLabs.** Владелец берёт платную подписку: бесплатный тариф — 10 000 кредитов в месяц, но без коммерческой
   лицензии и с обязательным упоминанием ElevenLabs, а обзор продаёт панель. Самый дешёвый коммерческий тариф —
   Starter (~$5–6/мес, 30 000 кредитов). Обзор на 5–7 мин ≈ 5–7 тыс. символов ≈ 5–7 тыс. кредитов
   на `eleven_multilingual_v2` (1 кредит за символ) — помещается с запасом на переозвучки и шортсы.
   Несколько бесплатных аккаунтов не заводим: это против правил сервиса, и коммерческих прав всё равно нет.
2. **Настройка.** Ключ и голос — в `.env` на сервере (в чат и в репозиторий не писать):
   `REELS_TTS=elevenlabs`, `REELS_ELEVENLABS_API_KEY`, `REELS_ELEVENLABS_VOICE_ID`
   (модель по умолчанию `eleven_multilingual_v2`, см. `src/video_mcp/reels/tts.py` — там уже есть синтез
   с таймингами слов). Голос выбрать по 3–4 коротким образцам одной фразы обзора. Сделать: вопрос про ElevenLabs
   в `deploy/reels-setup.sh` (сейчас он настраивает только голос через OpenAI-совместимый шлюз).
3. **Сценарий** 5–7 мин: основа — `docs/nexus/review-script.md` (11 мин, под живой голос владельца), сжать и
   переставить: сначала 5 фишек, которых нет у других (как в шортсе v2), потом ежедневное, в конце тарифы
   База 3 990 / Премиум 5 490 (таблица — `docs/nexus/README.md`; CDN и ИИ-помощник в Базе, Центр состояния,
   S3-туннель, API хостингов, автозамена нод и VIP — в Премиуме). Текст сначала согласовать с владельцем,
   только потом тратить кредиты.
4. **Картинка**: живая запись настоящей панели на демо-данных (`capture/record.mjs`) + графика скилла сверху:
   заголовки частей, наезды камерой на нужное, подписи, переходы. Возможно — сцена покупки в боте (рисовать)
   и подписка в приложении-клиенте (`docs/NEXUS_OVERVIEW.md`, «Подсказки для видео»).
5. **Озвучка → монтаж**: озвучиваем по частям, ElevenLabs отдаёт время каждого слова — по нему длина сцен,
   субтитры и паузы; записи экрана подгоняются под голос. Музыка под голосом приглушается (ducking).
   Переделка картинки кредитов не стоит, переозвучивается только изменённая фраза.

## Озвучка — `voice/synth.py`

Берёт блоки ```voice id=…``` из сценария, озвучивает каждый отдельно (`out/voice/<id>.mp3` + тайминги слов
в `<id>.json`). Ключ — только из окружения `ELEVENLABS_API_KEY` (в облачной среде: настройки среды → секреты
или переменные окружения; новая сессия его подхватит). Перед синтезом сверяет символы с остатком кредитов и без
`--yes` не тратит больше 1500 за запуск.

```bash
python3 voice/synth.py --count                     # символы по блокам (бесплатно)
python3 voice/synth.py --credits                   # остаток
python3 voice/synth.py --voices                    # голоса аккаунта
python3 voice/synth.py --samples ID1 ID2 ID3       # одна фраза разными голосами
python3 voice/synth.py --voice ID --blocks hook    # озвучить часть
```

Бесплатные 10 000 кредитов: образцы 3–4 голосов (~600) + пробная часть (~300), можно даже черновой прогон всего
текста (~4,7 тыс.) для чернового монтажа. Публиковать с бесплатного тарифа нельзя (нет коммерческой лицензии) —
чистовую озвучку делать уже на платном.

## Живая запись экрана — `capture/record.mjs`

```bash
python3 ../nexus-panel/capture/demo-brain.py 8099 &          # демо-данные
# панель из vgx3d/frontend: BRAIN_INTERNAL_URL=http://127.0.0.1:8099 npx next start -p 3100
node capture/record.mjs test                                   # → out/rec-test.mp4
```

- Окно 1280×720 при плотности 1.5 → кадр 1920×1080, интерфейс в полтора раза крупнее (как масштаб 150%
  в скринкастах): при 1920 CSS-пикселях панель на YouTube мелкая.
- Кадры — трансляцией Chromium (CDP `Page.startScreencast`, JPEG 85), не встроенной видеозаписью Playwright
  (та мылит). Кадр приходит, только когда экран меняется; по меткам времени ffmpeg собирает ровные 30 fps.
- Курсор рисуется в странице (своя стрелка + рябь на клике), движения по кривой с плавным разгоном.
  Подсказки графиков скрыты — курсор задевает их по пути.
- Сценарии записи — объект `SCENARIOS` в конце файла: под каждый кусок озвучки свой.

### Что улучшить до чистовой

- В движении трансляция даёт ~20 уникальных кадров/с (замер `mpdecimate`), курсор чуть ступенчатый.
  Варианты: писать путь курсора в лог и рисовать курсор в Remotion на 30 fps (страница сама по себе меняется
  редко), или снимать покадрово с виртуальным временем (CDP `Emulation.setVirtualTimePolicy`) — ровно, но
  запись в разы дольше реального времени.
- В заглушке правило `geosite:category-ads` панель помечает «deprecated geosite» (красная плашка
  на вкладке маршрутизации) — заменить на список доменов.
- Пробник: дашборд → серверы и вкладка маршрутизации → поиск клиента → Центр состояния и ИИ-разбор, 44 с.
