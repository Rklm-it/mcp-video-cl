# Аудит YouTube: как VPN-сервисы получают клиентов (07.10.2026)

Посмотрел выдачу YouTube по запросам «обход белых списков vpn» и «белые списки впн» (120 роликов) и разобрал
лидеров: транскрипт, описание, ссылки, цифры.

**Выводы:**
1. **Больше всего смотрят «бесплатно» и «честный разбор».** Люди ищут бесплатный способ. Самые популярные
   авторы сначала дают бесплатное (Zapret, ByeByeDPI для ПК), а потом говорят: «на телефоне при белых списках
   бесплатно не работает — бери платный за 200 ₽». Платный VPN продаётся *после* пользы.
2. **Сравнения и тесты** («купил 8 VPN и проверил на LTE») — много комментариев и доверия.
3. **Мемы** (переозвучка) — 122 тыс. просмотров. Охват огромный, но продаж в них нет — это для подписчиков.
4. **Канал самого VPN может работать.** Vosk VPN — 26 тыс. на познавательном ролике «как VPN обходят белые
   списки» с промокодом «cdn» на 3 дня. Это ровно наш формат s1.
5. **Ролик-реклама одного VPN без пользы** — 49 просмотров. Голая продажа не работает.

**Формула названия у лидеров:** «Как обойти белые списки» / «Обход белых списков» + **2026** + операторы
(МТС, Билайн, Мегафон, Т2) + «рабочий», «для всех регионов», «бесплатно», «на каждое устройство».
Описания — простыня ключевых слов (операторы, «не работает мобильный интернет», Happ, INCY, v2RayTun).

## 2. Как встраивают рекламу VPN

- **Через блогеров с партнёрскими ссылками.** У всех лидеров в описании 4–8 VPN-ботов со ссылками вида
  `t.me/NosokVPNBot?start=partner_...`, `?start=ref_...`. Блогер получает процент с оплат. Один и тот же VPN
  (Nosok, Capybara, Velvet, Quattro) встречается у разных авторов — **VPN-сервисы раскручиваются партнёрками,
  а не своими каналами.**
- **Встройка в рассказ, а не отдельный блок:** «я пользуюсь сам 3 месяца», «покупаю пакет 50 ГБ за 200 ₽,
  хватает на месяц». Личный опыт + цена + пробный период.
- **Живое доказательство:** выключил Wi-Fi → мобильный LTE → Telegram не грузит → включил VPN → грузит.
  Есть почти в каждом конвертящем ролике.
- **Промокод на пробный** (Vosk: «cdn» = 3 дня) — и повод перейти, и учёт, откуда клиент.
- **Бонус: прокси для Telegram** (потому что бот VPN сидит в Telegram, а Telegram при белых списках сам не грузится).
- **Посты в больших Telegram-каналах** (партнёрские материалы в новостных каналах) — второй главный канал рекламы.
- **Каталоги ботов** (telegramstore.org, minitelegram.com) и SEO-статьи «обход белых списков» на своих сайтах.

## 3. За что зрители и обзорщики хвалят и ругают VPN (это и есть конверсия)

| Плюс | Минус |
|---|---|
| Бесплатный пробный 3 дня (+ лимит МБ для белых списков) | Нет пробного — «тогда сразу минус» (даже лучшему ставят в упрёк) |
| Автовыбор сервера для белых списков | Перебирать 15 серверов вручную |
| Ключ можно скопировать вручную (для Happ / INCY / v2RayTun) | Только кнопки, ключ не скопировать |
| В пробном видно всё, что будет в платном | В пробном урезали белые списки — «значит, их нет» |
| Много пользователей, живой чат, отзывы | Маленький бот, «накрученные» цифры, нет комьюнити |
| До 5 устройств на подписку | 1–2 устройства |
| Скорость на LTE почти без потерь | 1 Мбит/с при белых списках |

## 4. Цены рынка и наши (белые списки)

| Сервис | Цена/мес | Что входит |
|---|---|---|
| Quattro | 300 ₽ | безлимит обычный + **500 ГБ** белые списки |
| Щука | 300 ₽ | безлимит + **100 ГБ** белые списки, 5 устройств |
| Velvet | 245 ₽ | 1 ТБ + **40 ГБ** белые списки, 5 устройств |
| Nosok, Capybara | 249–250 ₽ | безлимит, включая белые списки |
| Trust | 200 ₽ | **50 ГБ** мобильный пакет; обычный — 150 ₽ |
| Skip | 100 ₽ | **15 ГБ** белые списки, 2 устройства |
| Cola | 90 ₽ | **10 ГБ** белые списки; обычный — 100 ₽ |
| **Nexus сейчас** | **199 ₽** | **20 ГБ** белые списки; обычный «Анлим» — 249 ₽ отдельно |

**Вывод:** обычный VPN за 249 ₽ — в рынке. А белые списки у нас **дороже рынка за гигабайт**
(~10 ₽/ГБ против 2–6 ₽ у Trust, Щуки, Quattro), и они продаются отдельно от обычного VPN. Обзорщик
сравнения «за 100/300/500 ₽» нас бы за это опустил.
**Что можно сделать (если позволяет себестоимость трафика):** тариф-«комбо» около 299 ₽ — обычный
безлимит + 50 ГБ для белых списков, 3–5 устройств. Себестоимость белого трафика знаешь только ты — сначала
посчитать её.

## 5. Что берём себе — по приоритету

1. **Партнёрка для блогеров** — главный источник клиентов у всех конкурентов. В панели Nexus уже есть
   партнёры и рефкоды (`referral_code`, `referred_by`, раздел «Партнёры»). Найти 5–10 небольших каналов
   (2–30 тыс. просмотров на ролик про белые списки, как Гектор SHORTS, FINLAYER) и предложить 20–30% с оплат
   их зрителей по личной ссылке. Платим только за результат. Писать авторам — с «да» владельца.
2. **Свои шортсы продолжаем** (формат подтверждён — Vosk VPN, наш s1). Рецепт: польза → «я пользуюсь сам» →
   пробный → карточка.
3. **Одно длинное видео-инструкция 4–6 минут** — «Как обойти белые списки на МТС, Билайн, Мегафон, Т2 —
   2026, показываю на LTE»: выключаю Wi-Fi, ничего не грузится, включаю Nexus — работает. Это формат, который
   продаёт у всех. Нужна настоящая запись с телефона при белых списках. Шортсы ведут на это видео
   (в YouTube можно привязать «связанное видео» к шортсу).
4. **Промокод с пробным** для YouTube (как «cdn» у Vosk): например `NEXUS3` — 3 дня. Даёт и повод, и учёт.
5. **Проверить пробный глазами обзорщика:** даёт ли он белые списки, есть ли автовыбор сервера, можно ли
   скопировать ключ вручную, видно ли всё, что будет в платном. Если чего-то нет — это первое, за что ругают.
6. **Прокси для Telegram** как подарок в описании — частый «крючок».
7. **Каталоги ботов** (telegramstore.org, minitelegram.com) — бесплатно разместить карточку бота.
8. Мем-ролики — иногда, для подписчиков (не для продаж).

## 6. Аналитика на будущее — что считать каждую неделю

Сейчас в панели у пользователей есть поле `source`, но оно знает только «bot / manual / web / dealer» —
**откуда именно пришёл человек, не видно.** Нужно метить:
- ссылку на бота в описаниях YouTube делать с меткой (рефкод YouTube-канала или `?start=yt`);
- отдельный промокод для YouTube;
- каждому блогеру — свой партнёрский код.

| Показатель | Где брать | Цель на ноябрь |
|---|---|---|
| Просмотры шортсов за неделю | YouTube Студия | 5–10 тыс. |
| Подписчики канала | YouTube Студия | 300+ |
| «Смотрят / пролистнули», % досмотра | Аналитика ролика | > 60% не пролистывают |
| Новые пользователи бота с YouTube | панель (по метке/промокоду) | 30+ |
| Пробный → оплата | панель | 20–30% |
| Пользователи и оплаты от каждого блогера | панель, раздел «Партнёры» | 3+ блогера с оплатами |
| Заявки на панель в @Nexus_dev | личка | 2–3 |

Сверка раз в неделю: что выросло, какой ролик привёл людей в бота, какой блогер дал оплаты — неработающее
выкидываем, работающее повторяем.
