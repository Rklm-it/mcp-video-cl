## Правила для каждой статьи

1. Полезная статья сама по себе: читатель решает задачу даже без перехода по ссылке. Одна-две партнёрские ссылки.
2. **Тексты банковских офферов согласовать с менеджером Pampadu** (у ОТП: «использование рекламных материалов без
   согласования запрещено»). Рекламодатель у банковских офферов — сам банк (ОТП: АО «ОТП Банк», ИНН 7708001614).
3. **Рекламная пометка** рядом со ссылкой: «Реклама. {РЕКЛАМОДАТЕЛЬ}. erid: {ERID}». Юрлицо и erid берём в кабинете Pampadu
   по каждому офферу. Пока их нет — статью не публикуем со ссылкой.
3. Факты — только проверенные, с датой: «условия на сентябрь 2026, перед оформлением проверьте на сайте банка».
   Ставки — всегда «до …%» и с условием.
4. Финансовые продукты: название банка, существенные условия (ставка, срок, минимальная сумма, от чего зависит кешбэк).
   Не обещаем доход, не пишем «гарантированно».
5. Курьерский оффер: доход только «до 8 500 ₽ в день», без слов «работа, подработка, зарплата, трудоустройство,
   вакансия, сотрудник, оклад»; «партнёр сервиса Яндекс Еда»; выплаты ежедневные для граждан РФ и ЕАЭС.
6. Займы и кредиты не рекламируем.
7. Публикуем не пачкой: 2–3 статьи в неделю на площадку, чтобы не выглядеть спамом и не попасть под «коммерческий блог».
8. Каждая статья — отдельная метка в ссылке (sub2 = номер статьи), чтобы видеть, какая приносит клики.
