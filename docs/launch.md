# Запуск: схема и первые 3 дня (решено 27.09.2026)

Почему именно так — `docs/money-research.md`, `docs/plan-50k.md`. Этот файл — рабочий план, по нему идём.

## Схема заработка

```
                 ┌─→ клики по офферам ─→ Pampadu ─→ карта
СТАТЬИ ──────────┤
(vc.ru, Дзен,    └─→ TG-КАНАЛ ─┬─→ посты с офферами ─→ Pampadu
 Пикабу)                       ├─→ РСЯ / реклама (от 1000 подписчиков)
РОЛИКИ ─────────────→          └─→ БОТ ─→ звёзды ─→ Fragment ─→ TON ─→ карта
```

- **Статьи** — главный источник в месяцы 1–2: им не нужна своя аудитория, площадка сама показывает их людям.
  Каждая статья ведёт на подходящий по теме оффер и в канал/бот.
- **Канал и бот** стартуют пустыми и в первый месяц дают 0. Люди приходят из статей, роликов, поиска Telegram и
  пересылок (подпись бота на каждой картинке, бонус за друга). Платную рекламу покупаем, только когда в боте платит
  больше 5–6% пользователей.
- **Изюминка статей:** А — личный опыт с честными цифрами (владелец сам оформляет бесплатный продукт и мы пишем
  «месяц пользовался — вот сколько вернулось»); Б — история нашего проекта («фабрика ИИ-роликов за 130 ₽»,
  «доход с нейросетями с нуля, отчёт»). Канал — дневник проекта, поэтому не пустой с первого дня.
- **Сначала офферы Pampadu** — там erid и маркировку выдаёт сеть. Timeweb и Маркет напрямую — после проверки,
  кто маркирует рекламу.
- **На паузе до решения по цифрам:** ролики (кроме продвижения бота), Kliply, Авито, Timeweb/Маркет напрямую.

## Этапы

1. **Дни 1–3 — запуск всего сразу** (ниже).
2. **Дни 3–14 — публикуем по 1–2 статьи в день** (не пачкой), пост в канал каждый день, Claude смотрит статистику.
3. **День ~14 — решение по цифрам:** какая площадка не режет, какая тема даёт клики, сколько реально платит клик,
   платит ли кто-то в боте. Неработающее бросаем, работающее — ещё 5–10 статей.
4. **Месяцы 2–3 — усиление:** статьи-победители, взаимопиар канала (от 300–500 подписчиков), улучшение бота.
5. **Ноябрь–декабрь — новогодний пик** для бота и подарочных подборок. Потом 23 Февраля, 8 Марта.
6. **Через ~5 месяцев — самозанятость:** Kwork, Клипни, Ozon Блогер, оплата картой в боте, ИИ-услуги на Авито.

## Кто что делает

**Принцип:** владелец делает только то, что требует его личности: входы (логин, пароль, код из СМС), Telegram-приложение,
токены в `.env`, свои деньги и паспорт, и «да» перед каждой публикацией. **Всё остальное делает Claude** — в браузере
на VPS (MCP-BROWSER-CL, профили входов хранятся) и в коде на сервере.

Как Claude получает вход на сайт: владелец присылает логин и пароль (или код из СМС) для этого входа, Claude входит
в браузере с профилем `<сайт>`, дальше вход сохранён, пароль владелец меняет. Без пароля в чате: cookies через
Cookie-Editor → `mcp-browser profile-import <сайт> cookies.json` на сервере.

## День 1

### Владелец (≈30–40 минут)

1. **Входы для браузера Claude:** Pampadu (профиль `pampadu`), Яндекс ID (для Дзена и vc.ru, профиль `yandex`),
   Пикабу — если аккаунтов ещё нет, Claude регистрирует сам, владелец только присылает коды подтверждения.
2. **В Telegram-приложении** (браузером это не сделать):
   - создать новый канал (название — из вариантов Claude), добавить админом бота студии с правом публикации;
   - в BotFather `/newbot` — бот открыток; отозвать засветившийся токен бота студии и выпустить новый.
3. **На сервере в `.env`:** `CARDS_BOT_TOKEN`, новый `REELS_TG_BOT_TOKEN`, `MCP_BROWSER_TG_BOT_TOKEN` +
   `MCP_BROWSER_TG_CHATS` (канал) — чтобы Claude публиковал в канал через API после «да». Токены в чат не присылать.
4. **Личный тест:** открыть «Сейвы» в Яндекс Пэй (минуты), сохранять скриншоты условий и начислений.
5. **Ответить:** изюминка А, Б или обе (совет — обе); название канала; тема бота (совет — праздничные открытки с фото).

### Claude (весь день, параллельно)

1. **Pampadu в браузере:** офферы курьеры 2304, «Магнит Пэй», «Сейвы», ОТП Карта, ВТБ накопительный счёт, Кинопоиск
   + поиск новых с высоким EPC и разрешёнными статьями. По каждому: ссылка с меткой sub2, erid, юрлицо рекламодателя,
   нужно ли согласование. Тексты банков — на согласование через кабинет или куратора. Всё записать в
   `docs/offers.md`.
2. **Площадки в браузере:** оформить профили vc.ru, Дзена, Пикабу (имя, аватар, описание), изучить правила
   о рекламе и ссылках на каждой — чтобы первые статьи не улетели в бан.
3. **Бот открыток** — `bots/cards/`, отдельный сервис в docker compose: фото + повод → открытка через Gemini,
   3 бесплатные попытки, дальше звёзды, подпись бота на картинке, +3 попытки за друга, статистика (запуски,
   генерации, оплаты, источник по метке в /start). Тесты, пуш, владелец обновляет сервер.
4. **Статьи:** план 10–12 штук (минимум 6 офферов + 2 про проект), первые 3 на офферы без согласования.
5. **Канал:** 3 варианта названия, описание, аватар (Gemini), 5 первых постов-дневника.
6. **Учёт:** `docs/launch-stats.md` — статья → площадка → дата → просмотры → клики → деньги.

**Итог дня 1:** все входы у Claude, ссылки и erid собраны, профили площадок оформлены, бот написан, первые статьи готовы.

## День 2

- **Claude:** дописывает 8–10 статей, вставляет ссылки и erid, делает обложки; запускает бота на сервере и
  проверяет сам; готовит посты в канал.
- **Владелец:** читает статьи и правит, если хочет; проверяет бота на себе и 2–3 знакомых.

## День 3

- **Claude:** публикует первые статьи на vc.ru и Дзене и первый пост в канале — **каждую только после «да»
  владельца** (показывает текст или скриншот перед кнопкой).
- Дальше — по 1–2 статьи в день, пост в канал каждый день, ежедневная сводка цифр от Claude.

## День ~14 — решение по цифрам

Claude собирает статистику из кабинетов (Pampadu, площадки, бот) и предлагает: что бросить, что масштабировать.
