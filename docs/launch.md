# Запуск: схема и первые 3 дня (решено 27.09.2026)

Почему именно так — `docs/money-research.md`, `docs/plan-50k.md`. Этот файл — рабочий план, по нему идём.

## Схема заработка

```
                 ┌─→ клики по офферам ─→ Pampadu ─→ карта
СТАТЬИ ──────────┤
(vc.ru, Дзен,    └─→ TG-КАНАЛ ─┬─→ посты с офферами ─→ Pampadu
 Пикабу)                       ├─→ РСЯ / реклама (от 1000 подписчиков)
РОЛИКИ ─────────────→          └─→ БОТ ─→ звёзды ─→ Fragment ─→ TON ─→ карта
```

- **Статьи** — главный источник в месяцы 1–2: им не нужна своя аудитория, площадка сама показывает их людям.
  Каждая статья ведёт на подходящий по теме оффер и в канал/бот.
- **Канал и бот** стартуют пустыми и в первый месяц дают 0. Люди приходят из статей, роликов, поиска Telegram и
  пересылок (подпись бота на каждой картинке, бонус за друга). Платную рекламу покупаем, только когда в боте платит
  больше 5–6% пользователей.
- **Изюминка статей:** А — личный опыт с честными цифрами (владелец сам оформляет бесплатный продукт и мы пишем
  «месяц пользовался — вот сколько вернулось»); Б — история нашего проекта («фабрика ИИ-роликов за 130 ₽»,
  «доход с нейросетями с нуля, отчёт»). Канал — дневник проекта, поэтому не пустой с первого дня.
- **Сначала офферы Pampadu** — там erid и маркировку выдаёт сеть. Timeweb и Маркет напрямую — после проверки,
  кто маркирует рекламу.
- **На паузе до решения по цифрам:** ролики (кроме продвижения бота), Kliply, Авито, Timeweb/Маркет напрямую.

## Этапы

1. **Дни 1–3 — запуск всего сразу** (ниже).
2. **Дни 3–14 — публикуем по 1–2 статьи в день** (не пачкой), пост в канал каждый день, Claude смотрит статистику.
3. **День ~14 — решение по цифрам:** какая площадка не режет, какая тема даёт клики, сколько реально платит клик,
   платит ли кто-то в боте. Неработающее бросаем, работающее — ещё 5–10 статей.
4. **Месяцы 2–3 — усиление:** статьи-победители, взаимопиар канала (от 300–500 подписчиков), улучшение бота.
5. **Ноябрь–декабрь — новогодний пик** для бота и подарочных подборок. Потом 23 Февраля, 8 Марта.
6. **Через ~5 месяцев — самозанятость:** Kwork, Клипни, Ozon Блогер, оплата картой в боте, ИИ-услуги на Авито.

## День 1 — подробно

### Владелец (≈2–3 часа)

1. **Pampadu — только вход.** Офферы, ссылки, erid, согласования делает Claude сам в браузере на VPS (профиль
   `pampadu`). Владельцу нужно лишь дать вход: логин и пароль для этого входа (потом сменить пароль) или
   экспорт cookies расширением Cookie-Editor → на сервере `mcp-browser profile-import pampadu cookies.json`.
2. **Аккаунты на площадках** (один честный аккаунт на площадку):
   - vc.ru — вход через Яндекс ID или почту; аватар, имя, одна строка о себе («делаю проект с нейросетями
     и честно считаю деньги»);
   - Дзен — вход через Яндекс ID, создать канал с таким же именем и описанием;
   - Пикабу — аккаунт (публиковать будем позже, пусть «отлежится»).
3. **Telegram-канал** — новый, под дневник проекта и деньги (не курьерский @dohod_na_dostavke). Название выбрать
   из вариантов Claude, описание и аватар Claude подготовит. Добавить бота студии админом, чтобы Claude мог
   готовить посты.
4. **Бот для открыток** — в BotFather `/newbot`, имя и username со словами, которые ищут («открытка»,
   «поздравление»). Токен — **только в `.env` на сервере** (`CARDS_BOT_TOKEN=...`), не в чат.
   Заодно отозвать в BotFather старый токен бота студии, который засветился в логах, и вписать новый.
5. **Личный тест для изюминки А** — оформить один бесплатный продукт. Проще всего «Сейвы» в Яндекс Пэй
   (открывается в приложении за минуты); второй вариант — карта «Магнит Пэй» (доставка курьером).
   Сохранять скриншоты: условия при открытии, начисления.
6. **Ответить Claude:** изюминка А, Б или обе; название канала; тема бота (предложение — праздничные открытки
   с фото человека).

### Claude (параллельно)

0. **Pampadu через браузер:** по офферам (курьеры 2304, «Магнит Пэй», «Сейвы», ОТП Карта, ВТБ накопительный счёт,
   Кинопоиск и всё новое с высоким EPC и разрешёнными статьями) — ссылка с меткой sub2, erid, юрлицо рекламодателя,
   нужно ли согласование; отправить тексты на согласование через кабинет/куратора.
1. **Бот открыток, основа:** папка `bots/cards/`, отдельный сервис в docker compose. Функции первой версии:
   фото + повод → открытка через Gemini (как в фабрике роликов), 3 бесплатные попытки, дальше оплата звёздами,
   подпись с именем бота на картинке, +3 попытки за приглашённого друга, счётчики (запуски, генерации, оплаты,
   откуда пришёл — метка в /start).
2. **Список 10–12 тестовых статей:** тема, оффер, площадка, sub2. Минимум 6 разных офферов + 2 статьи Б
   (без партнёрских ссылок — проверить, как площадки принимают нас самих).
3. **Первые 3 статьи** — на офферы без согласования текста, чтобы опубликовать их первыми.
4. **Канал:** 3 варианта названия, описание, 5 первых постов-дневника.
5. **Таблица учёта** `docs/launch-stats.md`: статья → площадка → дата → просмотры → клики → деньги.
6. Тексты банковских офферов, которым нужно согласование (ОТП), — подготовить, чтобы владелец отправил менеджеру
   Pampadu в первый же день.

### Итог дня 1

Есть ссылки и erid, аккаунты, канал, токен бота на сервере; у Claude — каркас бота, план статей, первые тексты.

## День 2

Claude дописывает 8–10 статей и доводит бота; владелец читает и правит тексты, отправляет тексты банков на
согласование. Канал — первые посты.

## День 3

Первые публикации (Claude через браузер — только после «да» владельца по каждой), запуск бота на знакомых.
Дальше — по 1–2 статьи в день.
