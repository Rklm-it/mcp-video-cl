# «Ну и новости» — канал хайповых новостей

Отдельный от Nexus канал: хайповые новости дня, чтобы растить аудиторию; позже в нём рекламируется свой VPN.

- Telegram: `@nuinovosti_tv` · Instagram: `nu_i_novosti.tv` (ID `17841439672961934`, приложение Meta `nuinovosti`).
- Бренд в фабрике рилсов: `brand="news"` (`REELS_BRANDS`, ставится `deploy/brand-setup.sh`). Такой ролик уходит
  только в эти два канала; черновик в Telegram пишет «Куда: telegram, instagram».

## Формат ролика
- **Чужое видео + свой голос и надписи.** В сцене `media` — ссылка на страницу с видео (YouTube, VK, X, TikTok…),
  `media_start` — с какой секунды, `fit="blur"` — горизонтальное видео целиком посередине на размытой копии.
  Оригинальный звук вырезается, остаются наш голос, субтитры и `label` (крупная надпись сверху).
- 25–45 с, 4–6 сцен. Сцена 1 — хук с цифрой или вопросом, без разгона. Обложка — первый кадр.
- Подпись к посту — тот же вопрос-хук, 3–5 хэштегов.

## Конвейер
1. Утром Claude ищет 3–5 самых обсуждаемых новостей (Яндекс.Новости, Google Trends RU, крупные TG-каналы,
   Reddit, тренды YouTube), сверяет факты по двум источникам.
2. На каждую — ролик `create_reel(brand="news", after="review")` и пост.
3. Владелец жмёт «Опубликовать» в Telegram → Telegram-канал + Instagram.
