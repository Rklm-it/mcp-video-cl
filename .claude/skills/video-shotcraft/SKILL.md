# video-shotcraft для наших роликов

Оригинал — [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)
(Apache-2.0, сторонний скилл, не продукт Anthropic). В репозиторий он не положен: весит ~120 МБ.
Закреплённая версия скачивается в кэш:

```bash
SC=$(.claude/skills/video-shotcraft/fetch.sh)        # печатает путь к скиллу
SC=$(.claude/skills/video-shotcraft/fetch.sh --template)  # + зависимости шаблона Ink Press
```

**Дальше прочитай `$SC/SKILL.md` целиком и работай по нему** (режимы, порядок этапов,
`references/pipeline.md`, `references/aesthetic-rules.md`, карточки `references/shots/*` и
исходники `demos/`). Ниже — только то, что у нас отличается или добавляется.

## Готовый проект: промо панели Nexus

`promo/nexus-panel/` — вертикальный ролик 1080×1920, 26 с, сделанный по скиллу (режим
«автономное создание»). Новые ролики про панель начинай с него, а не с нуля:
сцены, камера под вертикаль, субтитры, звук и съёмка уже настроены. Как снять кадры
заново и отрендерить — `promo/nexus-panel/README.md`.

## Наши правила поверх скилла

1. **Данные в кадре только выдуманные.** Настоящих клиентов, доменов, IP и сумм не
   показываем (решение владельца, `docs/nexus/README.md`). Панель снимаем на демо-заглушке
   `promo/nexus-panel/capture/demo-brain.py`, не на живой панели и не на мастере.
2. **Снимаем настоящую панель, а не рисуем её** (правило Q1 скилла). Код панели — в
   репозитории `vgx3d` (`frontend/`): `npm ci && npx next build`, затем
   `BRAIN_INTERNAL_URL=http://127.0.0.1:8099 npx next start -p 3100` рядом с заглушкой.
3. **Шортсы — вертикаль и мобильная вёрстка панели.** Окно 540 px CSS ложится на кадр
   1080 ровно ×2; текстуры снимать в 4x, карточку, на которую наезжает камера, — в 8x.
   Камера скилла (`PageCam`) рассчитана на 1920×1080 — бери нашу `promo/nexus-panel/src/lib/Cam.tsx`.
4. **Первый кадр — уже собранная обложка** (`docs/nexus/style-guide.md`): тезис на 3 строки,
   средняя крупнее и цветом, внутри обрезки 3:4 (y 240…1680). Это сознательное отступление
   от `promo-energy-arc` скилла (там старт с бренда): у шортсов досмотр решают первые 2 с.
5. **Цвета — тема Nebula панели** (`frontend/src/app/globals.css`) + концовка канала
   (`docs/nexus/brand/endcard-panel.png`): фиолетовый фон, фуксия, бирюза. Токены — `promo/nexus-panel/src/theme.ts`.
6. **Текст в кадре — по-русски**, субтитр ≥56 px (Q11), ключевое слово на розовой плашке.
   Интерфейс Reels/Shorts закрывает низ (~350 px) и правый край — важное туда не ставить.
7. **Звук — только файлы с известным источником** из `$SC/assets/audio/ATTRIBUTION.md`
   (там у части файлов «无法反查» — источник не найден; такие не берём). Рендерим две версии:
   с музыкой и без (`npm run render` / `npm run render:nobgm`).
8. **Публикация — только после «да» владельца** (как и для остальных роликов, `CLAUDE.md`).
   Из шагов «после сдачи» оригинала (отметить автора, витрина, экспорт в CapCut-JianYing)
   владельцу нужно разве что предложить; сам скилл просит не настаивать.

## Проверка перед сдачей

- `npm run typecheck` в `promo/nexus-panel/`.
- Стоп-кадры каждой сцены: `npx remotion still src/index.ts NexusPromo out/qa/f<N>.png --frame=<N>`
  — смотреть глазами: резкость текста, стыки, ничего не лезет под интерфейс Reels.
- После рендера — кадры из готового mp4 (`ffmpeg -ss <сек> -i out/nexus-promo.mp4 -frames:v 1`)
  и громкость (`ffmpeg -i … -af volumedetect -f null -`).
- Независимая проверка по `$SC/references/final-review.md` — отдельным агентом с чистым контекстом,
  если владелец не против потратить на это время.
